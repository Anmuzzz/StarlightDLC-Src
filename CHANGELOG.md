# Changelog

## 2.6-beta-bf

### Исправлено
- **KillAura**: фликер между целями (гистерезис удержания цели), двойной raycast за тик (кэш на тик), прицел вне радиуса при пустых кандидатах, спам-пакеты отключения щита (один раз), мгновенный первый удар после входа в мир, удалены мёртвые поля (airTicks, attackWatch)
- **Автобай**: мёртвые проверки атрибутов/зачарований (неверный NBT-тип 9 → 10) — покупался любой тотем/талисман игнорируя требования (6 мест); цена соседнего слота-ценника была no-op; спам-матчинг пустых имён слотов (покупались денежные стаки); SpookyTime-парсер никогда не запускался (пустой резолвер); SpookyTime-хендлер игнорировал задержку обновления (двойные покупки); перекрытие цифр в Watermark
- **YouTube/плеер**: в jar не был вложен модуль `javafx-swing` — причина «JavaFX не найден» при загруженном JavaFX (добавлены нативы Windows и Linux); off-by-one в парсере `youtu.be`-ссылок (краш на коротких id); утечка GL-текстур превью; JFXPanel создаётся на EDT; Tab в Lua IDE вставлялся дважды (8 пробелов вместо 4)
- **Второй проход аудита**: цветовые каналы HitFX/TargetESP/JumpCircle (двойное масштабирование 0..255), утечка шейдера после эффекта «Взрыв», коллизии widthCache шрифтов (хеш-ключ), диагностический лог JavaFX с версией Java

### Оптимизировано
- MineStatus: два полных обхода всех сущностей мира за кадр → кэш скана на 500 мс, статический regex, без format→split→parse кругов
- DynamicIsland.statuses(): stream→toList→reversed несколько раз за кадр → кэш на 250 мс
- Часы островка: SimpleDateFormat каждый кадр → кэш на секунду
- ESP: GL-состояние и буферы один раз на кадр вместо раза на сущность; TNTTimer: один обход мира + кэш стека
- Кэши: модулей по имени и классу (getModule без stream по 110 модулям), строк KeyBinds, элементов HUD, обёрток шрифтов, статические regex (EntityUtility, EventStatus)

## 2.5.5-beta

### Добавлено
- **Lua-движок**: LuaScriptEngine (luaj-jse), модуль LuaModule, автозагрузка скриптов
- **Lua IDE**: экран редактора скриптов в модуле Lua — список файлов, редактор с кареткой/скроллом/кликом, New/Delete/Reload/Save, Ctrl+S и Ctrl+V; Save перезагружает скрипты
- Lua-движок: полная изоляция скриптов — у каждого свой Globals и свои подписки на события
- **YouTube поверх мира**: плавающее окно с видео — перетаскивание за тайтл-бар, ресайз за уголок (240–960px, 16:9), звук не прерывается при перетаскивании; кнопки пауза/в браузере/закрыть; поиск с превью в отдельном экране (Enter — искать); воспроизведение через встроенный JavaFX WebView (при наличии в classpath), иначе — фолбэк в системный браузер
- **Hit FX**: новый модуль визуалов при ударе — Ударная волна (расширяющееся кольцо), Взрыв (bloom-частицы), Вспышка (хитбокс), Искры (радиальные линии); мульти-выбор, цвет, размер, длительность
- Target ESP: новые режимы **Gradient** (градиентный диск под целью, стиль LiquidBounce) и **Halo** (вращающееся волновое кольцо-нимб с бегущими огнями)
- Velocity: рабочий режим **Reduce** (уменьшение отдачи на 50%)
- Zoom: поддержка мышечных биндов (нажатие/отпускание)
- NoPush: настройка «Вода» отключает толчок жидкостей, «Блоки» — выталкивание из блоков
- Производительность: кэш обёрток шрифтов в `MsdfFont.getFont` (HUD/меню аллоцировали их десятки раз за кадр), кэш модулей по классу в `ModuleManager` (getModule(Class) без stream-прохода по всем модулям)

### Исправлено

**Стабильность (краш-баги):**
- AntiBot: ConcurrentModificationException при удалении ботов из мира (итерация по живому списку игроков)
- BlockOverlay: ClassCastException во время затухания при взгляде на сущность; вспышка оверлея в точке (0,0,0) при MISS
- AutoAccept: ArrayIndexOutOfBoundsException на коротких сообщениях чата (двойная несогласованная проверка границ)
- FriendManager: NPE при вводе `.friend add` без ника
- MusicTracker: UnsupportedOperationException на не-Windows (clear() на immutable-списке) — медиа-худ и текст песни не обновлялись
- DrawUtility.drawBlur: push матрицы без pop при нулевом радиусе — разбаланс стека матриц всего UI
- ObjectInfo / ScreenCosmetic: translate без push/pop и pop внутри try с глушением исключений — порча матриц всему последующему рендеру
- CosmeticRenderer: GL-состояние (blend/cull/shaderColor) не восстанавливалось при ошибке рендера
- TPSHandler: NaN вместо 20.0 до прихода первого пакета времени
- ConfigUploadServer: обход пути в имени загружаемого конфига (сетевой доступ на запись) + гонка потоков — мутация конфигов вынесена на клиентский поток
- Localizator: утечка потоков ввода при ошибке загрузки языка (try-with-resources)

**Боевая система:**
- AutoTotem: таймер свапа сбрасывался каждый тик — тотем никогда не ставился при Delay ≥ 1
- AutoExplosion: сохранялась воздушная позиция кристалла вместо базовой (обсидиан) — модуль никогда не бил свои же кристаллы
- KillAura: дистанция до цели сравнивалась как квадрат с квадратом порога (неверная дистанция атаки); мёртвые флаги спринта — восстановление спринта не работало
- ShiftTap: отсчёт декрементировался в тик нажатия — при hold=2 шифт не попадал в опрос ввода вообще, при hold>2 тап короче на тик
- AutoWarden: «ближайший» варден брался по порядку выдачи сущностей; два зелья инвиза выпивались в один тик; слот возвращался сразу после использования и прерывал питьё
- AutoWeapon: в урон оружия суммировался штраф скорости атаки — неверный выбор лучшего оружия
- TargetComparators: «плохая броня» считала количество заполненных слотов (всегда ≤4) вместо очков брони
- NeuroAuraSystem: сглаживание ротации никогда не работало (последние углы не сохранялись, коэффициент 0)
- AutoTotem/AutoEat/AutoInvisible/AutoSprint/ElytraRecast: залипание клавиш (use/sprint/forward/jump) после выключения; инвертированные guard'ы в onDisable

**Передвижение и игрок:**
- Speed: инвертированное направление страйфа (клавиша A двигала вправо)
- Velocity: режим Reduce ничего не делал — реализован
- ElytraTarget / ElytraRecast / NoWeb / SuperFirework: инвертированные hide-условия — настройки скрывались ровно когда были нужны и показывались когда ничего не делали (свыше 20 параметров)
- SuperFirework: режим Custom не давал буста, слайдер Speed не читался
- MineHelper: pitch = yaw в пакете броска пузырька опыта — бросок в мусорном направлении
- RotationMath.getNearestPoint(entity, pos): параметр pos полностью игнорировался (pos−pos = 0)
- AutoLeave: pvpNoLeave полностью блокировал режим «Мало Хп» (порог 6 HP всегда срабатывал раньше)
- AutoTool: слот с инструментом не возвращался после завершения майнинга; lastItem рос без ограничений
- AirStuck: настройка «Cancel movement» ни на что не влияла
- AutoDuel: координаты не инициализировались в onEnable — мгновенное выключение модуля дальше 500 блоков от (0,0,0)
- AutoJoin: спам командой присоединения 20 раз/сек — троттлинг 500 мс
- Assist: дублирующая недостижимая ветка обработки кнопки
- ReHubCommand: продублированный isFT() — повторная попытка «/an» не срабатывала на родственных серверах
- ItemSlot.syncId: клики по слотам инвентаря игрока адресовались в открытый контейнер (сундук) — паковался чужой лут

**Визуалы и рендер:**
- TargetESP: синус в градусах вместо радиан (высота кристаллов), поворот свиней по орбите (atan2), восстановление depth-test
- KillEffects: восстановление depth-test после рендера
- JumpCircle: круг рисковался как GL_LINES-полоса (рваное кольцо); при нескольких кругах появлялись линии между ними — LINE_STRIP + отдельный буфер на круг
- ItemRadius: инвертированный winding граней + включённый back-face culling — заливка куба-трапки невидима снаружи
- ShulkerPreview: всегда-истинный тернарник (превью для любого предмета) и недостижимая ветка light_gray (перепутан порядок проверок с gray)
- Ambience: сохранялся world time вместо time of day — при выключении время суток скакало
- Prediction: |vx+vz| схлопывался на диагональных траекториях — снаряды игнорировались
- ParticleEffects: дублированное условие дистанции
- TNTTimer: пульсация таймера не работала (константная цель анимации)
- PVPAI: альфа 0..1 подавалась в цветовую шкалу 0..255 — цифры урона были невидимы
- ObjectInfo: усечение координат вместо floor — метки трапок смещались на блок в отрицательных координатах
- ColorRGBA: getSaturation и getBrightness перепутаны местами (портило ColorPicker)
- Векторная анимация: update() жёстко ставила значение вместо интерполяции; getVec() обрезала результат до целых

**Косметика:**
- CosmeticModel.withType: создавала пустую копию модели — все пользовательские косметики из typed-папок не рендерились и не имели анимаций
- CosmeticBbAnimation: поле loop в bbmodel — строковый enum («loop»/«once»/«hold»), парсился как boolean — все зацикленные анимации застывали на последнем кадре
- CosmeticTextureSlot: UV делились на размер картинки вместо UV-канвы (uv_width) — HD-текстуры рендерились кропом 4x
- CosmeticModel: нормализация UV-диапазонов стирала зеркалирование граней (нашивки/текст на неправильной стороне у встроенных моделей)
- CosmeticHeldItemRenderer: натяжение лука нормировалось на 72000 тиков (анимация никогда не играла); квадратичный член ванильной формулы завышен в 20 раз; трансформации применялись без порога натяжения
- MixinCosmeticRenderer: push/pop матриц перенесены в try/finally

**UI и HUD:**
- AutoBuyScreen: правый клик по предмету инвертировал флаг парсера цены; панель настроек открывалась и тут же схлопывалась; закрытие анимировалось от чужой переменной
- KeyBinds: мёртвый guard (== вместо !=) — сортировка биндов никогда не выполнялась
- IRCScreen: чат рисовался вниз от нижнего якоря — новые сообщения уходили за экран; теперь вверх
- MineStatus: захардкоженные координаты шахты FunTime вместо серверозависимых — таймер шахты никогда не показывался на HolyWorld
- DynamicIsland: пипетка адаптивного цвета читала пиксель без учёта scale factor — у кромки экрана вместо фона острова
- ItemRender (3 метода): setShaderColor вызывался ПОСЛЕ отрисовки — предметы не затухали, цвет протекал в следующие элементы кадра
- TextField: граница клика каретки сдвинута на ширину символа (оба места) — курсор ставился не туда
- TargetHud: клик по нику цели копировал свой ник; NPE без игрока
- ChangelogScreen: заголовок сравнивался со старой версией «1.2.0» — хедер никогда не подсвечивался
- ModeSetting/SelectSetting: хит-тест строк значений смещён на 9px и на 14px шире отрисованных строк — «призрачные» клики мимо панели

**Сеть и AutoBuy:**
- NetworkManager: price-sync протокол мёртв в обе стороны (итерация пустого HashMap + пустой handlePriceSync); цена от парсера-чекера не применялась к товару; повторный start() плодил бесконечные циклы подключения до исчерпания пула потоков
- PurchaseHandler: regex цены HolyWorld не допускал разделителей разрядов — покупки не распознавались
- AfkHandler: клавиши движения залипали при выходе из AFK во время нажатия
- ModuleManager: raw setEnabled(boolean) в MenuCloseListener пропускал отписку слушателей и onDisable — анимация закрытия меню не играла, повторное открытие дублировало подписки
- MouseMixin: события отпускания кнопки мыши не доходили до слушателей
- ChatInputSuggestor: асинхронный ci.cancel() был no-op — ванильное окно подсказок конкурировало с командным
- ClientConnectionMixin: волатильность флага, guard'ы на менеджер событий, try/finally вокруг переотправки пакета
- ClientPlayerEntityMixin: setYaw вместо setPitch в server-ротации
- ConfigFile: ключ бинда по умолчанию 0 вместо -1 (модули без бинда получали «0»)
- ClientDataFile: сессия из client.myth создавалась и выбрасывалась — ник не применялся; null-защита на пустой JSON
- elegant: порядок инициализации подсистем и null-guard'ы при сохранении конфигов на выключении

**Утилиты:**
- Timer.finished: инвертированная логика отсчёта
- WorldUtility: CopyOnWriteArrayList вместо ArrayList (список читается рендером, пишется сетью)
- ParticleUtil: отскоки частиц усиливали скорость в ~2.2 раза вместо затухания
- ScrollHandler: адаптивный easing применялся только при скролле в одну сторону
- TPSHandler: NaN-защита

**Локализация:**
- uk_ua: +32 ключа, pl_pl: +33 ключа, ru_ru: +1 ключ — вместо текста настроек показывались сырые ключи вида `modules.descriptions.shifttap`

**Lua-система:**
- Reload скриптов дублировал подписки на события — скрипты начинали срабатывать 2x, 4x, 8x после каждой перезагрузки (выгрузка не снимала колбэки)
- Ошибка одного .lua-файла прерывала загрузку остальных и ломала включение модуля (необработанное исключение в цикле)
- Песочница: `require`, `os.execute`, `os.exit`, `os.remove`, `os.rename`, `os.getenv`, `io.open`, `io.popen` и др. были доступны вопреки заявленной изоляции
- Скрипты делили один Globals — могли перезаписывать глобальные переменные и функции друг друга
- KeyBinds: `show()` собирал список через stream+toList на каждый кадр вместо anyMatch
